# OneDragon Studio · AI漫剧一条龙

**简体中文** | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Français](README.fr.md) | [Español](README.es.md) | [العربية](README.ar.md)

从剧本到成片的 AI 漫剧流水线，Web 界面，本地部署。

```
剧本 → AI 拆分镜 → 角色/场景资产 → 分镜首帧 → 图生视频 → 配音字幕 → 合成成片
```

- **流程化**：每一步的产物都存下来、都能在网页里改；改了哪一步就从哪一步重跑，不用推倒重来。
- **后台任务队列**：耗时操作排队执行，失败自动重试，关掉网页、重启服务都能接着跑。不需要 Redis / Docker。
- **模型可插拔**：文本大模型内置 DeepSeek、OpenAI、Google Gemini、Anthropic Claude、Azure OpenAI、OpenRouter、阿里云百炼、火山方舟、Ollama 预设，也支持任意 OpenAI 兼容接口，海外接口可配代理；生图、生视频可选云端平台（阿里云百炼、火山方舟，不用 GPU）或 ComfyUI（本机或远程 GPU 服务器）。
- **竖屏优先**：默认 9:16，面向快手 / 抖音的短剧与漫剧。

## 快速开始（Windows）

需要 Python 3.10+ 和 Node.js 18+。

双击 `start.bat`。首次运行会自动安装依赖并打包前端，然后打开 http://127.0.0.1:8100 。

然后：

1. 打开「设置」，填文本大模型的地址、模型名和你自己的 API Key，点「保存并测试连接」。
2. 回到「项目」，新建一部剧。点「导入故事或小说」（TXT / EPUB / 粘贴），按章节标题、AI 按剧情或按字数拆成多集，预览时可以改标题、合并、勾选；也可以新建一集把剧本贴进去。
3. 点「AI 拆分镜」，几十秒后得到分镜表：场景、景别、运镜、画面、台词、首帧提示词、视频提示词，都可以直接改。
4. 回到项目页，「一键生成缺少的参考图」给角色、场景、道具出参考图（也可以上传自己的）。
5. 在分镜表里「批量生成首帧」→「批量生成视频」，或者逐个镜头重新生成。
6. 或者直接点分集页的「一键成片」：自动走完拆分镜 → 参考图 → 首帧 → 视频 → 配音 → 合成，已有的不重做；哪一步失败会停下来说明原因，修好后再点一次接着跑。
7. 点「合成成片」：自动补齐台词配音，烧录字幕和「AI生成」标识，拼成一个 MP4，在页面底部预览、下载（附 SRT 字幕）。

配音默认用 Edge 在线朗读（免费、免 Key，非官方接口），也可以换成 OpenAI 兼容的 `/audio/speech` 接口（比如自己部署的 CosyVoice）。角色可以单独指定音色，没指定的按外貌描述里的性别自动选。

其他几个页面：

- **素材库**：项目里的角色、场景、道具点「存入素材库」，在别的项目里「从素材库导入」，同一个角色在第二部剧里长相、音色不变。
- **提示词**：AI 拆分镜、AI 分集、参考图模板都可以在网页上改，改坏了一键恢复默认。
- **AI 日志**：每次调用大模型发了什么、回了什么、用了多少 tokens，拆分镜结果不对时先来这里看。

## 不用 GPU 出真画面：云端平台

「系统设置」里把生图 / 生视频供应商选成 **阿里云百炼**（通义万相 wan2.6）或 **火山方舟**（豆包 Seedream / Seedance），填上你自己的 API Key 就能出真画面，按张 / 按秒计费，价格以平台为准。

- 镜头首帧会自动带上出镜角色、道具、场景的参考图（最多 4 张），人物前后更一致。
- 视频只生成画面（关掉平台自带配音），配音、字幕、AI 标识由本工具统一处理。
- 模型名可以在设置里改，平台出了新模型直接换名字即可。「保存并测试 API Key」只验证 Key，不生成内容、不花钱。

默认是「演示」供应商：不调用任何模型，出带文字的占位图和缓慢推近的占位视频，用来先把流程走通。

## 接 ComfyUI

生图、生视频不绑定具体模型，用你自己在 ComfyUI 里调好的工作流：

1. 在 ComfyUI 里搭好工作流并手动跑通，菜单选「导出 (API)」得到 JSON。
2. 把每次要变的输入值改成占位符，例如正向提示词 `"text": "{{prompt}}"`、空 Latent 的 `"width": "{{width}}"`。
3. 「设置」里把地址指向 ComfyUI（本机或租用的 GPU 服务器），粘贴三个工作流，生图 / 生视频供应商选 ComfyUI。

| 工作流 | 用途 | 必需占位符 |
| --- | --- | --- |
| 文生图 | 角色/场景参考图；没有参考图时的镜头首帧 | `{{prompt}}` |
| 参考图生图（可选） | 镜头首帧带上出镜角色、道具、场景的参考图（最多 3 张） | `{{prompt}}` `{{ref_image_1}}` |
| 图生视频 | 首帧 + 视频提示词 → 这一镜的视频 | `{{image}}` `{{prompt}}` |

其他可用占位符：`{{negative}}` `{{seed}}` `{{width}}` `{{height}}` `{{ref_image_2}}` `{{ref_image_3}}` `{{frames}}` `{{fps}}` `{{duration}}` `{{filename_prefix}}`。整个值就是占位符时按原类型替换（数字还是数字）；夹在文字里时按文字拼接。图片会自动上传到 ComfyUI，结果自动下载回来。

提示词默认是中文，选能理解中文的模型（如 Qwen-Image、Wan 系列、混元）效果最好。

## 开发模式

```bash
# 后端（端口 8100）
cd backend
python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\python -m uvicorn app.main:app --port 8100 --reload --reload-dir app

# 前端（端口 5174，接口自动代理到 8100）
cd frontend
npm install
npm run dev
```

接口文档：http://127.0.0.1:8100/docs

## 目录结构

```
backend/
  app/
    main.py            入口：路由、静态文件、启动任务队列
    models.py          数据模型：项目、分集、镜头、角色、场景、道具、素材库、AI 日志、任务、设置
    prompts.py         可在网页上修改的提示词模板
    routers/           HTTP 接口
    services/          业务流程（拆分镜、任务队列……）
    providers/         模型供应商（LLM、ComfyUI……）
  data/                运行数据（数据库、生成的图片视频），不进 git
frontend/              React + Vite 网页
```

## 数据与隐私

API Key、剧本、生成的素材都只存在本机 `backend/data/`，不会上传到任何地方（调用你配置的模型接口除外）。该目录已在 `.gitignore` 中排除。
