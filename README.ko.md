# OneDragon Studio · AI漫剧一条龙

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md) | **한국어** | [Français](README.fr.md) | [Español](README.es.md) | [العربية](README.ar.md)

> 참고: 웹 인터페이스는 영어와 중국어 간체를 지원합니다(사이드바 하단의 「中 / EN」으로 전환).

대본에서 완성 영상까지 이어지는 AI 만화 드라마 파이프라인으로, 웹 인터페이스를 갖추고 로컬에 배포합니다.

```
대본 → AI 콘티 분할 → 캐릭터/장면 에셋 → 콘티 첫 프레임 → 이미지→영상 생성 → 더빙·자막 → 최종 영상 합성
```

- **단계별 워크플로**: 각 단계의 결과물이 모두 저장되고 웹 페이지에서 수정할 수 있습니다. 수정한 단계부터 다시 실행하면 되므로 처음부터 다시 할 필요가 없습니다.
- **백그라운드 작업 큐**: 시간이 오래 걸리는 작업은 큐에 넣어 실행하고, 실패하면 자동으로 재시도하며, 웹 페이지를 닫거나 서비스를 재시작해도 이어서 실행됩니다. Redis / Docker가 필요 없습니다.
- **교체 가능한 모델**: 텍스트 LLM은 DeepSeek, OpenAI, Google Gemini, Anthropic Claude, Azure OpenAI, OpenRouter, Alibaba Cloud Model Studio, Volcano Engine Ark, Ollama 프리셋을 기본 제공하며, 모든 OpenAI 호환 API도 사용할 수 있습니다(해외 API용 프록시 설정 가능). 이미지·영상 생성은 클라우드 플랫폼(Alibaba Cloud Model Studio(阿里云百炼), Volcano Engine Ark(火山方舟), GPU 불필요) 또는 ComfyUI(로컬 또는 원격 GPU 서버) 중에서 선택할 수 있습니다.
- **세로 화면 우선**: 기본 비율은 9:16이며, Kuaishou / Douyin용 숏드라마와 만화 드라마를 대상으로 합니다.

## 빠른 시작(Windows)

Python 3.10+ 및 Node.js 18+가 필요합니다.

`start.bat`을 더블클릭합니다. 처음 실행하면 의존성을 자동으로 설치하고 프런트엔드를 빌드한 뒤 http://127.0.0.1:8100 을 엽니다.

그다음:

1. **설정**(「设置」)을 열고 텍스트 LLM의 주소, 모델 이름, 본인의 API Key를 입력한 뒤 **저장 및 연결 테스트**(「保存并测试连接」)를 클릭합니다.
2. **프로젝트**(「项目」)로 돌아가 새 드라마를 만듭니다. **이야기 또는 소설 가져오기**(「导入故事或小说」)(TXT / EPUB / 붙여넣기)를 클릭해 챕터 제목 기준, AI의 줄거리 판단 기준 또는 글자 수 기준으로 여러 에피소드로 나눕니다. 미리보기에서 제목 수정, 병합, 선택이 가능합니다. 새 에피소드를 만들어 대본을 직접 붙여넣을 수도 있습니다.
3. **AI 콘티 분할**(「AI 拆分镜」)을 클릭하면 수십 초 후 콘티표가 생성됩니다. 장면, 숏 사이즈, 카메라 무빙, 화면, 대사, 첫 프레임 프롬프트, 영상 프롬프트를 모두 직접 수정할 수 있습니다.
4. 프로젝트 페이지로 돌아가 **누락된 참조 이미지 일괄 생성**(「一键生成缺少的参考图」)으로 캐릭터, 장면, 소품의 참조 이미지를 생성합니다(직접 업로드할 수도 있습니다).
5. 콘티표에서 **첫 프레임 일괄 생성**(「批量生成首帧」) → **영상 일괄 생성**(「批量生成视频」)을 실행하거나, 숏별로 하나씩 다시 생성합니다.
6. 또는 에피소드 페이지에서 바로 **원클릭 완성**(「一键成片」)을 클릭합니다. 콘티 분할 → 참조 이미지 → 첫 프레임 → 영상 → 더빙 → 합성을 자동으로 모두 진행하며, 이미 있는 결과물은 다시 만들지 않습니다. 어느 단계에서 실패하면 멈추고 원인을 알려 주므로, 문제를 해결한 뒤 다시 클릭하면 이어서 실행됩니다.
7. **최종 영상 합성**(「合成成片」)을 클릭합니다. 대사 더빙을 자동으로 채우고 자막과 "AI 생성"(「AI生成」) 표시를 입힌 뒤 하나의 MP4로 이어 붙입니다. 페이지 하단에서 미리보기하고 다운로드할 수 있습니다(SRT 자막 포함).

더빙은 기본적으로 Edge 온라인 낭독(무료, Key 불필요, 비공식 인터페이스)을 사용하며, OpenAI 호환 `/audio/speech` 인터페이스(예: 직접 배포한 CosyVoice)로 바꿀 수도 있습니다. 캐릭터별로 음색을 따로 지정할 수 있고, 지정하지 않으면 외모 설명에 나온 성별에 따라 자동으로 선택됩니다.

그 밖의 페이지:

- **에셋 라이브러리**(「素材库」): 프로젝트의 캐릭터, 장면, 소품에서 **에셋 라이브러리에 저장**(「存入素材库」)을 클릭하고, 다른 프로젝트에서 **에셋 라이브러리에서 가져오기**(「从素材库导入」)를 하면 같은 캐릭터가 두 번째 드라마에서도 외모와 음색이 그대로 유지됩니다.
- **프롬프트**(「提示词」): AI 콘티 분할, AI 에피소드 분할, 참조 이미지 템플릿을 모두 웹에서 수정할 수 있으며, 잘못 수정해도 클릭 한 번으로 기본값을 복원할 수 있습니다.
- **AI 로그**(「AI 日志」): LLM을 호출할 때마다 무엇을 보냈고 무엇을 받았는지, tokens를 얼마나 사용했는지 기록됩니다. 콘티 분할 결과가 이상할 때 먼저 여기를 확인하세요.

## GPU 없이 실제 화면 생성: 클라우드 플랫폼

**시스템 설정**(「系统设置」)에서 이미지 / 영상 생성 공급자를 **Alibaba Cloud Model Studio(阿里云百炼)**(Tongyi Wanxiang wan2.6) 또는 **Volcano Engine Ark(火山方舟)**(Doubao Seedream / Seedance)로 선택하고 본인의 API Key를 입력하면 실제 화면을 생성할 수 있습니다. 이미지 장수 / 영상 초 단위로 과금되며, 가격은 각 플랫폼 기준을 따릅니다.

- 숏의 첫 프레임에는 등장 캐릭터, 소품, 장면의 참조 이미지(최대 4장)가 자동으로 첨부되어 인물의 일관성이 높아집니다.
- 영상은 화면만 생성하며(플랫폼 자체 더빙은 끔), 더빙, 자막, AI 표시는 이 도구에서 일괄 처리합니다.
- 모델 이름은 설정에서 변경할 수 있으므로, 플랫폼에 새 모델이 나오면 이름만 바꾸면 됩니다. **저장 및 API Key 테스트**(「保存并测试 API Key」)는 Key만 검증하며, 콘텐츠를 생성하지 않고 비용도 발생하지 않습니다.

기본값은 **데모**(「演示」) 공급자입니다. 어떤 모델도 호출하지 않고, 텍스트가 들어간 자리표시 이미지와 천천히 줌인하는 자리표시 영상을 만들어 먼저 전체 흐름을 확인하는 데 사용합니다.

## ComfyUI 연동

이미지·영상 생성은 특정 모델에 묶여 있지 않으며, ComfyUI에서 직접 조정한 워크플로를 사용합니다.

1. ComfyUI에서 워크플로를 구성하고 수동으로 정상 실행되는지 확인한 뒤, 메뉴에서 "Export (API)"를 선택해 JSON을 얻습니다.
2. 매번 바뀌어야 하는 입력값을 자리표시자로 바꿉니다. 예: 긍정 프롬프트 `"text": "{{prompt}}"`, 빈 Latent의 `"width": "{{width}}"`.
3. **설정**(「设置」)에서 주소를 ComfyUI(로컬 또는 임대한 GPU 서버)로 지정하고 워크플로 세 개를 붙여넣은 뒤, 이미지 / 영상 생성 공급자를 ComfyUI로 선택합니다.

| 워크플로 | 용도 | 필수 자리표시자 |
| --- | --- | --- |
| 텍스트→이미지 | 캐릭터/장면 참조 이미지, 참조 이미지가 없을 때의 숏 첫 프레임 | `{{prompt}}` |
| 참조 이미지→이미지(선택) | 숏 첫 프레임에 등장 캐릭터, 소품, 장면의 참조 이미지 첨부(최대 3장) | `{{prompt}}` `{{ref_image_1}}` |
| 이미지→영상 | 첫 프레임 + 영상 프롬프트 → 해당 숏의 영상 | `{{image}}` `{{prompt}}` |

그 밖에 사용할 수 있는 자리표시자: `{{negative}}` `{{seed}}` `{{width}}` `{{height}}` `{{ref_image_2}}` `{{ref_image_3}}` `{{frames}}` `{{fps}}` `{{duration}}` `{{filename_prefix}}`. 값 전체가 자리표시자이면 원래 타입대로 치환되고(숫자는 숫자 그대로), 텍스트 중간에 들어 있으면 텍스트로 이어 붙입니다. 이미지는 ComfyUI에 자동으로 업로드되고 결과는 자동으로 다운로드됩니다.

프롬프트는 기본적으로 중국어이므로, 중국어를 이해하는 모델(예: Qwen-Image, Wan 시리즈, Hunyuan)을 선택하면 가장 좋은 결과를 얻을 수 있습니다.

## 개발 모드

```bash
# 백엔드(포트 8100)
cd backend
python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\python -m uvicorn app.main:app --port 8100 --reload --reload-dir app

# 프런트엔드(포트 5174, API는 8100으로 자동 프록시)
cd frontend
npm install
npm run dev
```

API 문서: http://127.0.0.1:8100/docs

## 디렉터리 구조

```
backend/
  app/
    main.py            진입점: 라우팅, 정적 파일, 작업 큐 시작
    models.py          데이터 모델: 프로젝트, 에피소드, 숏, 캐릭터, 장면, 소품, 에셋 라이브러리, AI 로그, 작업, 설정
    prompts.py         웹에서 수정할 수 있는 프롬프트 템플릿
    routers/           HTTP 인터페이스
    services/          비즈니스 흐름(콘티 분할, 작업 큐 등)
    providers/         모델 공급자(LLM, ComfyUI 등)
  data/                실행 데이터(데이터베이스, 생성된 이미지·영상), git에 포함되지 않음
frontend/              React + Vite 웹 페이지
```

## 데이터와 개인정보

API Key, 대본, 생성된 에셋은 모두 로컬의 `backend/data/`에만 저장되며, 어디에도 업로드되지 않습니다(사용자가 설정한 모델 API 호출 제외). 이 디렉터리는 `.gitignore`에서 제외되어 있습니다.
