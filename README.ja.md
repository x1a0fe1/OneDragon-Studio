# OneDragon Studio · AI漫剧一条龙

[简体中文](README.md) | [English](README.en.md) | **日本語** | [한국어](README.ko.md) | [Français](README.fr.md) | [Español](README.es.md) | [العربية](README.ar.md)

> Web インターフェースは英語と簡体字中国語に対応しています（サイドバー下部の「中 / EN」で切り替え）。

脚本から完成動画までを一貫して制作できる AI コミックドラマ（漫剧）パイプラインです。Web インターフェースで操作し、ローカル環境にデプロイして使います。

```
脚本 → AI による絵コンテ分割 → キャラクター／シーン素材 → カットの最初のフレーム → 画像から動画生成 → ボイスと字幕 → 完成動画に合成
```

- **ワークフロー型**：各ステップの成果物はすべて保存され、Web ページ上で編集できます。どこかのステップを修正したら、そのステップから再実行するだけで済み、最初からやり直す必要はありません。
- **バックグラウンドのタスクキュー**：時間のかかる処理はキューに入れて実行され、失敗すると自動でリトライします。Web ページを閉じても、サービスを再起動しても、続きから処理を再開します。Redis や Docker は不要です。
- **モデルを差し替え可能**：テキスト生成には DeepSeek、OpenAI、Google Gemini、Anthropic Claude、Azure OpenAI、OpenRouter、Alibaba Cloud Model Studio、Volcano Engine Ark、Ollama のプリセットを内蔵し、任意の OpenAI 互換 API にも対応します（海外 API 用のプロキシも設定可能）。画像生成・動画生成は、クラウドプラットフォーム（Alibaba Cloud Model Studio（阿里云百炼）、Volcano Engine Ark（火山方舟）。GPU 不要）か ComfyUI（ローカルまたはリモートの GPU サーバー）から選べます。
- **縦型動画優先**：デフォルトは 9:16 で、快手（Kuaishou）／抖音（Douyin）向けのショートドラマやコミックドラマを想定しています。

## クイックスタート（Windows）

Python 3.10 以上と Node.js 18 以上が必要です。

`start.bat` をダブルクリックしてください。初回実行時は依存関係のインストールとフロントエンドのビルドが自動で行われ、その後 http://127.0.0.1:8100 が開きます。

続いて、以下の手順で進めます。

1. **設定**（「设置」）を開き、テキスト用大規模言語モデルのエンドポイント、モデル名、ご自身の API Key を入力して、**保存して接続テスト**（「保存并测试连接」）をクリックします。
2. **プロジェクト**（「项目」）に戻り、新しいドラマを作成します。**物語または小説をインポート**（「导入故事或小说」）（TXT / EPUB / 貼り付け）をクリックすると、章タイトル、AI による筋書き判定、または文字数に基づいて複数のエピソードに分割できます。プレビュー画面ではタイトルの変更、結合、選択が可能です。新しいエピソードを作成して脚本を直接貼り付けることもできます。
3. **AI 絵コンテ分割**（「AI 拆分镜」）をクリックすると、数十秒で絵コンテ表が生成されます。シーン、ショットサイズ、カメラワーク、画面内容、セリフ、最初のフレーム用プロンプト、動画用プロンプトはすべて直接編集できます。
4. プロジェクトページに戻り、**不足している参考画像をワンクリック生成**（「一键生成缺少的参考图」）でキャラクター、シーン、小道具の参考画像を生成します（自作の画像をアップロードすることもできます）。
5. 絵コンテ表で **最初のフレームを一括生成**（「批量生成首帧」）→ **動画を一括生成**（「批量生成视频」）を実行するか、カットごとに個別に再生成します。
6. または、エピソードページの **ワンクリック成片**（「一键成片」）を直接クリックします。絵コンテ分割 → 参考画像 → 最初のフレーム → 動画 → ボイス → 合成までを自動で実行し、既に生成済みのものは作り直しません。いずれかのステップで失敗した場合は停止して原因を表示するので、問題を修正したらもう一度クリックすれば続きから処理されます。
7. **完成動画を合成**（「合成成片」）をクリックすると、不足しているセリフのボイスを自動で補い、字幕と **AI 生成**（「AI生成」）の表示を焼き込んで 1 本の MP4 にまとめます。ページ下部でプレビューとダウンロード（SRT 字幕付き）ができます。

ボイスはデフォルトで Edge のオンライン読み上げ（無料、Key 不要、非公式 API）を使用しますが、OpenAI 互換の `/audio/speech` API（たとえば自分でデプロイした CosyVoice）に切り替えることもできます。キャラクターごとに声を個別に指定でき、指定がない場合は外見の説明に含まれる性別から自動で選ばれます。

その他のページ：

- **素材ライブラリ**（「素材库」）：プロジェクト内のキャラクター、シーン、小道具で **素材ライブラリに保存**（「存入素材库」）をクリックし、別のプロジェクトで **素材ライブラリからインポート**（「从素材库导入」）を使えば、2 作目のドラマでも同じキャラクターの見た目や声が変わりません。
- **プロンプト**（「提示词」）：AI 絵コンテ分割、AI エピソード分割、参考画像のテンプレートはすべて Web ページ上で編集でき、壊してしまってもワンクリックでデフォルトに戻せます。
- **AI ログ**（「AI 日志」）：大規模言語モデルを呼び出すたびに、何を送り、何が返ってきて、何 tokens を消費したかを記録します。絵コンテ分割の結果がおかしいときは、まずここを確認してください。

## GPU なしで本物の映像を生成：クラウドプラットフォーム

**システム設定**（「系统设置」）で画像生成／動画生成のプロバイダーを **Alibaba Cloud Model Studio（阿里云百炼）**（Tongyi Wanxiang（通义万相）wan2.6）または **Volcano Engine Ark（火山方舟）**（Doubao Seedream / Seedance）に設定し、ご自身の API Key を入力すれば、本物の映像を生成できます。料金は画像枚数／動画の秒数単位の従量課金で、価格は各プラットフォームの表示に準じます。

- カットの最初のフレームには、登場するキャラクター、小道具、シーンの参考画像（最大 4 枚）が自動で添付されるため、人物の見た目がカット間でより一貫します。
- 動画は映像のみを生成し（プラットフォーム側の音声生成はオフにします）、ボイス、字幕、AI 生成表示は本ツールでまとめて処理します。
- モデル名は設定画面で変更でき、プラットフォームで新しいモデルが公開されたら名前を書き換えるだけで切り替えられます。**保存して API Key をテスト**（「保存并测试 API Key」）は Key の検証のみを行い、コンテンツは生成しないため料金はかかりません。

デフォルトは **デモ**（「演示」）プロバイダーです。モデルを一切呼び出さず、テキスト入りのプレースホルダー画像と、ゆっくりズームインするプレースホルダー動画を出力するので、まずはワークフロー全体を一通り試すのに使えます。

## ComfyUI との連携

画像生成・動画生成は特定のモデルに縛られず、ComfyUI でご自身が調整したワークフローを使用します。

1. ComfyUI でワークフローを組み、手動で正常に実行できることを確認したら、メニューから **エクスポート (API)**（「导出 (API)」）を選んで JSON を取得します。
2. 毎回変化させたい入力値をプレースホルダーに置き換えます。たとえばポジティブプロンプトは `"text": "{{prompt}}"`、空の Latent は `"width": "{{width}}"` のようにします。
3. **設定**（「设置」）でアドレスを ComfyUI（ローカルまたはレンタルした GPU サーバー）に向け、3 つのワークフローを貼り付けて、画像生成／動画生成のプロバイダーに ComfyUI を選択します。

| ワークフロー | 用途 | 必須プレースホルダー |
| --- | --- | --- |
| テキストから画像生成 | キャラクター／シーンの参考画像、参考画像がない場合のカットの最初のフレーム | `{{prompt}}` |
| 参考画像から画像生成（任意） | 登場するキャラクター、小道具、シーンの参考画像（最大 3 枚）を添えたカットの最初のフレーム | `{{prompt}}` `{{ref_image_1}}` |
| 画像から動画生成 | 最初のフレーム + 動画用プロンプト → そのカットの動画 | `{{image}}` `{{prompt}}` |

その他に使えるプレースホルダー：`{{negative}}` `{{seed}}` `{{width}}` `{{height}}` `{{ref_image_2}}` `{{ref_image_3}}` `{{frames}}` `{{fps}}` `{{duration}}` `{{filename_prefix}}`。値全体がプレースホルダーの場合は元の型のまま置換されます（数値は数値のまま）。文字列の途中に埋め込まれている場合は文字列として連結されます。画像は ComfyUI に自動でアップロードされ、結果も自動でダウンロードされます。

プロンプトはデフォルトで中国語のため、中国語を理解できるモデル（Qwen-Image、Wan シリーズ、Hunyuan（混元）など）を選ぶと最も良い結果が得られます。

## 開発モード

```bash
# バックエンド（ポート 8100）
cd backend
python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\python -m uvicorn app.main:app --port 8100 --reload --reload-dir app

# フロントエンド（ポート 5174、API は自動で 8100 にプロキシ）
cd frontend
npm install
npm run dev
```

API ドキュメント：http://127.0.0.1:8100/docs

## ディレクトリ構成

```
backend/
  app/
    main.py            エントリーポイント：ルーティング、静的ファイル、タスクキューの起動
    models.py          データモデル：プロジェクト、エピソード、カット、キャラクター、シーン、小道具、素材ライブラリ、AI ログ、タスク、設定
    prompts.py         Web ページ上で編集できるプロンプトテンプレート
    routers/           HTTP API
    services/          業務フロー（絵コンテ分割、タスクキューなど）
    providers/         モデルプロバイダー（LLM、ComfyUI など）
  data/                実行時データ（データベース、生成された画像・動画）、git 管理対象外
frontend/              React + Vite の Web フロントエンド
```

## データとプライバシー

API Key、脚本、生成された素材はすべてローカルの `backend/data/` にのみ保存され、どこにもアップロードされません（ご自身で設定したモデル API の呼び出しを除く）。このディレクトリは `.gitignore` で除外されています。
