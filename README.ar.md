- **سير عمل مرحلي**: تُحفظ مخرجات كل خطوة ويمكن تعديلها من صفحة الويب؛ وإذا عدّلت خطوة ما أُعيد التشغيل منها فقط، دون الحاجة إلى البدء من الصفر.
- **قائمة مهام في الخلفية**: تُصفّ العمليات الطويلة وتُنفَّذ بالترتيب، ويُعاد تشغيل الفاشل منها تلقائيًا، وتستمر المهام حتى بعد إغلاق الصفحة أو إعادة تشغيل الخدمة. لا حاجة إلى Redis / Docker.
- **نماذج قابلة للتبديل**: للنصوص إعدادات جاهزة مدمجة لـ DeepSeek، OpenAI، Google Gemini، Anthropic Claude، Azure OpenAI، OpenRouter، Alibaba Cloud Model Studio، Volcano Engine Ark، SiliconFlow، Ollama، إضافةً إلى أي واجهة متوافقة مع OpenAI، مع إمكانية ضبط وكيل (proxy) للواجهات الخارجية؛ أما توليد الصور والفيديو فيمكن عبر منصات سحابية (Alibaba Cloud Model Studio (阿里云百炼)، Volcano Engine Ark (火山方舟)، دون الحاجة إلى GPU) أو عبر ComfyUI (على جهازك أو على خادم GPU بعيد).
- **الأولوية للشاشة العمودية**: النسبة الافتراضية 9:16، موجّهة للمسلسلات القصيرة ومسلسلات الكوميكس على Kuaishou / Douyin.

## البدء السريع (Windows)

يتطلّب Python 3.10+ و Node.js 18+.

انقر نقرًا مزدوجًا على `start.bat`. في التشغيل الأول تُثبَّت الاعتماديات تلقائيًا وتُبنى الواجهة الأمامية، ثم تُفتح http://127.0.0.1:8100 .

بعد ذلك:

1. افتح **الإعدادات** (「设置」)، واملأ عنوان نموذج اللغة الكبير النصي واسم النموذج ومفتاح API الخاص بك، ثم انقر **حفظ واختبار الاتصال** (「保存并测试连接」).
2. ارجع إلى **المشاريع** (「项目」) وأنشئ مسلسلًا جديدًا. انقر **استيراد قصة أو رواية** (「导入故事或小说」) (TXT / EPUB / لصق)، وقسّمها إلى حلقات حسب عناوين الفصول أو حسب الحبكة بالذكاء الاصطناعي أو حسب عدد الأحرف؛ ويمكنك أثناء المعاينة تعديل العناوين والدمج والتحديد. ويمكنك أيضًا إنشاء حلقة جديدة ولصق السيناريو فيها.
3. انقر **تقطيع اللقطات بالذكاء الاصطناعي** (「AI 拆分镜」)، وبعد بضع عشرات من الثواني تحصل على جدول اللقطات: المشهد، وحجم اللقطة، وحركة الكاميرا، والصورة، والحوار، وموجّه الإطار الأول، وموجّه الفيديو، وكلها قابلة للتعديل مباشرة.
4. ارجع إلى صفحة المشروع، واستخدم **توليد الصور المرجعية الناقصة بنقرة واحدة** (「一键生成缺少的参考图」) لإنشاء صور مرجعية للشخصيات والمشاهد والدعائم (أو ارفع صورك الخاصة).
5. في جدول اللقطات استخدم **توليد الإطارات الأولى دفعةً واحدة** (「批量生成首帧」) ← **توليد الفيديوهات دفعةً واحدة** (「批量生成视频」)، أو أعد توليد كل لقطة على حدة.
6. أو انقر مباشرة **حلقة بنقرة واحدة** (「一键成片」) في صفحة الحلقة: يُنفَّذ تلقائيًا تقطيع اللقطات ← الصور المرجعية ← الإطارات الأولى ← الفيديو ← التعليق الصوتي ← المونتاج، دون إعادة ما أُنجز من قبل؛ وإذا فشلت خطوة ما يتوقف ويشرح السبب، وبعد إصلاحه انقر مرة أخرى ليُكمل.
7. انقر **المونتاج النهائي** (「合成成片」): يُكمل تلقائيًا التعليق الصوتي الناقص للحوار، ويدمج الترجمة النصية ووسم **مُولَّد بالذكاء الاصطناعي** (「AI生成」) في الصورة، ثم يجمع كل شيء في ملف MP4 واحد يمكنك معاينته وتنزيله أسفل الصفحة (مع ملف ترجمة SRT).

يستخدم التعليق الصوتي افتراضيًا القراءة عبر الإنترنت من Edge (مجانية، دون مفتاح، واجهة غير رسمية)، ويمكن استبدالها بواجهة `/audio/speech` متوافقة مع OpenAI (مثل CosyVoice الذي تنشره بنفسك). ويمكن تحديد صوت خاص لكل شخصية، وما لم يُحدَّد له صوت يُختار تلقائيًا حسب الجنس المذكور في وصف المظهر.

صفحات أخرى:

- **مكتبة الأصول**: انقر **حفظ في مكتبة الأصول** (「存入素材库」) على الشخصيات والمشاهد والدعائم في المشروع، ثم **استيراد من مكتبة الأصول** (「从素材库导入」) في مشروع آخر، فتبقى ملامح الشخصية نفسها وصوتها كما هي في المسلسل الثاني.
- **الموجّهات**: يمكن تعديل موجّهات تقطيع اللقطات بالذكاء الاصطناعي، وتقسيم الحلقات بالذكاء الاصطناعي، وقوالب الصور المرجعية من صفحة الويب، وإن أفسدتها فاستعد الافتراضي بنقرة واحدة.
- **سجل الذكاء الاصطناعي**: ما أُرسل إلى النموذج الكبير في كل استدعاء، وما عاد منه، وكم tokens استُهلك؛ وإذا جاءت نتيجة تقطيع اللقطات غير صحيحة فابدأ من هنا.

## صور حقيقية دون GPU: المنصات السحابية

في **إعدادات النظام** (「系统设置」) اختر مزوّد توليد الصور / الفيديو **Alibaba Cloud Model Studio (阿里云百炼)** (Tongyi Wanxiang wan2.6) أو **Volcano Engine Ark (火山方舟)** (Doubao Seedream / Seedance)، وأدخل مفتاح API الخاص بك لتحصل على صور حقيقية، مع احتساب التكلفة لكل صورة / لكل ثانية، والأسعار وفق ما تحدّده المنصة.

- يتضمّن الإطار الأول لكل لقطة تلقائيًا الصور المرجعية للشخصيات والدعائم والمشهد الظاهرة فيها (حتى 4 صور)، فتبقى الشخصيات أكثر اتساقًا من لقطة إلى أخرى.
- يولَّد الفيديو صورةً فقط (مع تعطيل الصوت المدمج في المنصة)، أما التعليق الصوتي والترجمة النصية ووسم الذكاء الاصطناعي فتتولاها هذه الأداة بشكل موحّد.
- يمكن تغيير اسم النموذج من الإعدادات؛ وإذا أطلقت المنصة نموذجًا جديدًا فما عليك إلا تغيير الاسم. زر **حفظ واختبار مفتاح API** (「保存并测试 API Key」) يتحقق من المفتاح فقط، دون توليد أي محتوى ودون أي تكلفة.

المزوّد الافتراضي هو **تجريبي** (「演示」): لا يستدعي أي نموذج، بل يُنتج صورًا مؤقتة عليها نص وفيديوهات مؤقتة بتقريب بطيء، لتجربة سير العمل كاملًا أولًا.

## الربط مع ComfyUI

توليد الصور والفيديو غير مرتبط بنموذج بعينه، بل يستخدم مسارات العمل التي ضبطتها بنفسك في ComfyUI:

1. ابنِ مسار العمل في ComfyUI وشغّله يدويًا حتى ينجح، ثم اختر من القائمة **تصدير (API)** (「导出 (API)」) لتحصل على ملف JSON.
2. استبدل قيم المدخلات التي تتغيّر في كل مرة بعناصر نائبة، مثل الموجّه الإيجابي `"text": "{{prompt}}"`، و `"width": "{{width}}"` في Latent الفارغ.
3. في **الإعدادات** (「设置」) وجّه العنوان إلى ComfyUI (على جهازك أو على خادم GPU مستأجر)، والصق مسارات العمل الثلاثة، واختر ComfyUI مزوّدًا لتوليد الصور / الفيديو.

| مسار العمل | الاستخدام | العناصر النائبة المطلوبة |
| --- | --- | --- |
| نص إلى صورة | الصور المرجعية للشخصيات/المشاهد؛ والإطار الأول للقطة عند غياب الصور المرجعية | `{{prompt}}` |
| صورة مرجعية إلى صورة (اختياري) | الإطار الأول للقطة مع الصور المرجعية للشخصيات والدعائم والمشهد الظاهرة فيها (حتى 3 صور) | `{{prompt}}` `{{ref_image_1}}` |
| صورة إلى فيديو | الإطار الأول + موجّه الفيديو ← فيديو هذه اللقطة | `{{image}}` `{{prompt}}` |

عناصر نائبة أخرى متاحة: `{{negative}}` `{{seed}}` `{{width}}` `{{height}}` `{{ref_image_2}}` `{{ref_image_3}}` `{{frames}}` `{{fps}}` `{{duration}}` `{{filename_prefix}}`. إذا كانت القيمة كلها عنصرًا نائبًا استُبدلت بنوعها الأصلي (يبقى الرقم رقمًا)؛ وإذا جاءت وسط نص دُمجت كنص. تُرفع الصور تلقائيًا إلى ComfyUI، وتُنزَّل النتائج تلقائيًا.

الموجّهات بالصينية افتراضيًا، لذا تكون أفضل النتائج مع النماذج التي تفهم الصينية (مثل Qwen-Image وسلسلة Wan و Hunyuan).

</div>

```bash
# الواجهة الخلفية (المنفذ 8100)
cd backend
python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\python -m uvicorn app.main:app --port 8100 --reload --reload-dir app

# الواجهة الأمامية (المنفذ 5174، وتُمرَّر طلبات الواجهة البرمجية تلقائيًا إلى 8100)
cd frontend
npm install
npm run dev
```
